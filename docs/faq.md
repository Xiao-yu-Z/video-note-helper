# 常见问题与排查（FAQ）

下面汇总高频报错与对应解决方案。所有功能均依赖本地运行环境，遇到问题时优先检查浏览器扩展权限与平台页面状态。

---

## 一、字幕提取失败

**Q1：提示「该视频暂无公开字幕 / 未找到公开字幕」**
- 在播放器中**手动开启字幕（CC）**后重试；部分视频本身没有字幕。
- YouTube：确认字幕语言已在播放器中选择；自动生成字幕（CC）需视频已启用。
- B站：部分老视频仅有 AI 字幕，等待加载完成后再提取。
- 百度网盘：请先在播放器开启「AI 字幕」，并播放一段时间让字幕加载。

**Q2：提示「未能从链接中识别 BV 号 / 未能获取 cid」**
- 请确认当前处于 B站**视频播放页**（URL 含 `BVxxxx`），而非个人主页或列表页；刷新页面后重试。

**Q3：字幕内容乱码或为空**
- 多为网络/接口临时异常，点击「提取字幕」重新尝试；B站接口偶发限流，稍候即可。

**Q3.1：之前「字幕无法提取」，现在仍失败 / 一直 Loading**
- 早期版本在内容脚本里直接 `fetch` 平台接口，会被浏览器**跨域（CORS）拦截**；B站 `x/player/wbi/v2` 还需 **WBI 签名**（依赖 MD5）。v1.0.0 已修复：所有接口请求改由**后台 Service Worker 代发（proxyFetch）**绕过 CORS，B站主路径改为 **WBI 签名请求**，并保留「免签名 / 旧版接口」两层兜底。
- 若仍失败，优先排查：
  1. 是否处于**视频播放页**（B站 URL 含 `BVxxxx`、YouTube 在 watch 页、百度网盘在播放页）；
  2. 视频是否**确有公开字幕**（AI 字幕需在播放器手动开启后加载）；
  3. 打开控制台（F12 → Console）看是否有 `-412 / -404 / 网络错误`，多为平台限流或登录态缺失，刷新或登录后重试。
- WBI 签名依赖的 MD5 已替换为经验证的 blueimp/JavaScript-MD5 实现（此前自写 MD5 在第 4 轮有常量错误，会导致所有 B站签名请求失败）。

## 二、大模型 API 调用失败

**Q4：提示「密钥错误（401）」**
- 检查设置中的 `API Key` 是否完整、有无多余空格；部分平台需要在 Key 前加 `Bearer ` 前缀（本项目已自动添加，请勿重复填写）。

**Q5：提示「额度不足或被限流（429）」**
- 账户余额不足或触发速率限制；充值或降低请求频率后重试。

**Q6：提示「请求超时 / 网络错误」**
- 检查 `API Base URL` 是否正确（**无需**包含 `/chat/completions`）。
- 本插件当前标签页的 `base_url` 需可被浏览器直接访问；若是本地模型（如 Ollama），确认服务已启动且端口可访问。
- 某些供应商需要额外请求头（如 `api-version`），当前版本未内置，可反馈需求。

## 三、Obsidian 同步失败

**Q7：提示「Obsidian 未启动 / 接口不通」**
- 确认 Obsidian 已打开且 **Local REST API** 插件已启用。
- 确认设置中的「接口地址」与插件显示一致（默认 `http://127.0.0.1:27123`）。
- 检查防火墙是否拦截了该本地端口。

**Q8：提示「密钥错误（401）」**
- 重新在 Obsidian 的 Local REST API 插件中生成 API Key，并粘贴到扩展设置。

**Q9：提示「目录不存在（404）」**
- 请先在 Obsidian 库内**手动创建**设置中填写的笔记目录与附件目录（如 `VideoNotes`、`VideoNotes/attachments`）。插件不会自动创建库内目录。

**Q10：同步成功但 Obsidian 中找不到笔记**
- 检查「笔记保存目录」「按平台建子目录」设置，笔记实际位于 `库根/笔记目录/平台子目录/` 下；同步成功提示中会给出完整路径，可直接复制打开。

## 四、截帧 / 配图相关

**Q11：点击「插入当前帧」没有反应或报错**
- 确认页面处于视频播放页且 `<video>` 已加载；部分浏览器对跨域视频的 canvas 读取会受限，本插件会**自动回退为截取可见标签页画面**（即播放器所在窗口画面），仍可作为配图。
- 若回退截图为空，请确保播放器画面在屏幕可见区域，再重试。

**Q12：自动截帧后视频进度被改动**
- 自动模式会拖动播放进度以截取各章节起始帧，结束后会回到开头；属正常现象。

## 五、安装与权限

**Q13：加载扩展后工具栏没有图标 / 面板不出现**
- 确认加载的是 `src/` 目录（含 `manifest.json`），而非仓库根目录。
- 确认扩展已「启用」；在支持的视频页刷新一次。
- 检查浏览器是否为较新版本（Manifest V3 需 Chrome 88+ / Edge 88+）。

**Q14：担心隐私 / 数据上传**
- 本项目**全程本地运行**：字幕、截图、配置、生成内容均仅保存在你的浏览器或本地 Obsidian 中，无任何中转服务器，插件不收集任何用户信息。详见 README 免责声明。
