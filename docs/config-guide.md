# 配置教程（Config Guide）

本扩展的两大外部依赖均需**用户自行提供**：① 一个大模型 API（OpenAI 兼容）；②（可选）Obsidian 的 Local REST API 用于同步。本插件**不内置任何密钥、不默认指向任何收费接口**。

打开配置页：点击工具栏图标 → 「⚙️ 打开设置」，或右键扩展 →「选项」。

---

## 一、配置大模型 API

> 支持任何兼容 OpenAI `/v1/chat/completions` 接口的供应商（如 OpenAI、Azure OpenAI、DeepSeek、通义千问、本地 Ollama 等）。

| 字段 | 说明 | 示例 |
| --- | --- | --- |
| API Base URL | 接口根地址，**无需**包含 `/chat/completions`，插件会自动拼接 | `https://api.openai.com/v1` |
| API Key | 你的密钥，仅保存在本地浏览器 | `sk-...` |
| 模型名称 | 实际调用的模型 ID | `gpt-4o-mini` |
| Temperature | 生成随机性，0–2，默认 0.4 | `0.4` |
| 最大输出 Token | 单次生成上限，默认 2000 | `2000` |

填写后点击 **「测试大模型连接」** 验证连通性。返回「✅ 连接成功」即配置正确。

> **本地模型（Ollama）示例**：Base URL 填 `http://127.0.0.1:11434/v1`，模型填 `qwen2.5`，Key 可随便填（如 `ollama`）。

---

## 二、配置 Obsidian 同步（可选）

### 第 1 步：安装 Obsidian 插件

1. 打开 Obsidian → 设置 → 第三方插件 → 关闭「安全模式」。
2. 浏览社区插件，搜索 **Local REST API** 并安装、启用。
3. 在插件设置中点击 **「New API Key」** 生成授权密钥，复制备用。
4. 记录接口地址（默认 `http://127.0.0.1:27123`）与授权密钥。

> ⚠️ 同步前请先在 Obsidian 库内**手动创建**对应的笔记目录与附件目录（如 `VideoNotes` 与 `VideoNotes/attachments`），否则同步会报「目录不存在」。

### 第 2 步：在扩展设置中填写

| 字段 | 说明 | 示例 |
| --- | --- | --- |
| 接口地址 | Obsidian Local REST API 地址 | `http://127.0.0.1:27123` |
| 授权密钥 | 上一步生成的 Key | `a1b2c3...` |
| 笔记保存目录 | 相对库根目录的笔记路径 | `VideoNotes` |
| 附件保存目录 | 相对库根目录的图片路径 | `VideoNotes/attachments` |
| 按平台建子目录 | 在目录内再分 `bilibili/`、`youtube/`、`baidu/` | 开启 |
| 文件名规则 | `标题` / `标题_日期` / `日期_标题` | `标题` |
| 覆盖已存在 | 同名文件直接覆盖 | 开启 |
| 生成后自动同步 | 生成笔记后自动写入 Obsidian | 关闭 |

### 第 3 步：验证

进入视频页生成笔记后点击 **「同步 Obsidian」**。成功后面板提示笔记路径，并自动打开 `obsidian://` 链接跳转；若 Obsidian 未启动或接口不通，会给出对应中文排查提示。

## 三、配图与笔记设置

- **图片格式 / 清晰度**：默认 JPEG、质量 0.75；追求无损可选 PNG（体积更大）。
- **最大宽度**：截帧压缩后的最长边像素，默认 720，兼顾清晰度与体积。
- **期望配图数量**：生成笔记时模型参考的目标配图数（3–6）。
- **YAML 元字段 / 默认标签**：自定义笔记头部元数据与标签。
- **自定义系统提示词**：留空使用内置结构化笔记模板；可填写专属指令以控制输出风格。

> 所有配置项均**仅保存在浏览器本地**（`chrome.storage.local`），不会上传任何服务器。
