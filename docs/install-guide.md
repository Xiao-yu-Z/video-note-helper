# 安装教程（Install Guide）

本教程覆盖在 **Chrome** 与 **Edge** 浏览器中加载「Video Note Helper」扩展的完整流程。本项目为 Manifest V3 扩展，纯原生实现，**无需 npm 安装、无需构建工具**。

---

## 一、获取源码

- **方式 A（推荐用于使用）**：点击仓库的 `Code → Download ZIP`，解压后进入 `video-note-helper/src/` 目录。
- **方式 B（用于二次开发/上传 GitHub）**：`git clone` 本仓库，源码位于 `src/` 目录。

> 加载扩展时请选择 **`src/` 文件夹**（包含 `manifest.json` 的那一层），而不是仓库根目录。

---

## 二、Chrome 加载已解压扩展

1. 打开浏览器，地址栏输入并访问 `chrome://extensions`。
2. 右上角打开 **开发者模式（Developer mode）** 开关。
3. 点击左上角 **加载已解压的扩展程序（Load unpacked）**。
4. 在文件选择器中选中本项目的 `src/` 目录，点击「选择文件夹」。
5. 扩展列表中应出现「Video Note Helper · 视频图文笔记助手」，状态为「已启用」。

---

## 三、Edge 加载已解压扩展

1. 地址栏访问 `edge://extensions`。
2. 左下角开启 **开发人员模式**。
3. 点击 **加载解压缩的扩展**，选择 `src/` 目录。
4. 确认扩展已启用。

---

## 四、固定到工具栏

点击浏览器右上角的「拼图」扩展图标，将「Video Note Helper」固定，方便随时打开状态弹窗与设置页。

---

## 五、验证安装

1. 点击工具栏图标，弹窗应显示「正在检测当前页面…」，随后提示是否在支持的平台。
2. 进入一个 B站 / YouTube 视频播放页，点击工具栏扩展图标 → **「打开笔记面板」**，页面右下角浮出操作面板（面板不会自动弹出，按需打开）。
3. 若提示「面板未就绪」，请刷新页面后重试；仍不行请见 [faq.md](faq.md)。

---

## 六、更新扩展

当源码有更新时，回到 `chrome://extensions` 页面，点击本扩展卡片上的 **刷新（↻）** 图标即可重新加载；若修改了 `manifest.json` 则需移除后重新加载。

---

## 七、卸载

在 `chrome://extensions` 页面找到本扩展，点击「移除」即可。本地存储的设置与历史记录会一并清除（如需备份请在设置页导出）。
